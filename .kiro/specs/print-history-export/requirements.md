# 打印历史导出需求

产品版本：`1.0.0` 准正式版维护增强；功能基线：v2 手动优先
更新时间：2026-10-08；前端归属：R100-16

## REQ-01 业务范围

用户在打印历史页面打开导出弹窗，独立编辑筛选并选择 Excel 或 PDF，下载全部匹配记录，不受列表页码影响。打开时复制已应用的列表条件，也可恢复列表条件或重置为全部历史；修改导出筛选不改变页面列表，不要求先查询列表。仅包含平台创建的 `COMPLETED/FAILED/CANCELLED` 任务，兼容历史 `CANCELED`；不包含设备外部打印。每次任务尝试计为一条记录，不能将记录条数解释为打印件数。

## REQ-02 权限与历史字段

ADMIN 可导出全部或指定创建人的记录；OPERATOR 仅能导出自己创建的任务，身份来自当前 JWT。文件、打印机、机台号、创建人、操作员使用历史快照优先的名称，资源更名或删除后仍保留可用的历史信息。任务编号必须保持文本，避免 Excel 大整数精度损失。

## REQ-03 筛选与统计

筛选包含终态、文件名、打印机、创建人、结束时间范围；时区固定 `Asia/Shanghai`，与现有历史页面一致。汇总和明细使用同一次有界查询的记录，提供记录条数、各结果条数和经过时长合计。经过时长为开始至结束，包含暂停；缺失或异常时间留空，不虚构净打印时间、耗材用量或打印件数。

## REQ-04 文件与限制

Excel 使用 `.xlsx`，第一张默认工作表为打印记录明细，第二张保留统计汇总；明细包含全部13字段与匹配记录，提供表头、筛选、冻结及正确的文本/日期/数字类型，文本不能成为公式。PDF 使用 A4 横向紧凑表格，一行对应一条记录、续页重复表头，汇总紧凑排列；正常30条记录不超过3页且字号不低于8pt。嵌入中文字体，长文件名和错误原因自动换行；极长文本在表格显示预览和明确附录引用，在全宽附录保留完整字段、记录标识并支持续页，不静默截断或丢失字段。空结果返回有效的零记录报告。同步导出默认 XLSX 10000 条、PDF 1000 条，配置只能降低，输出最多 20 MiB；超限返回 422 并提示缩小筛选范围，不静默截断。

## REQ-05 可复用架构与下载

独立接口 `POST /api/v1/print-jobs/history/export`；打印业务决定权限、查询和统计，公共导出模块只负责文档生成。将来其他业务新增自己的导出接口并复用公共模块，本次不增加通用任务中心或审计导出。前端保留全局认证处理，识别 JSON 错误，正确读取文件名，防重复和过期会话下载，卸载时清理请求与临时 URL。

## REQ-06 验证边界

覆盖权限、筛选、真实 SQLite 查询、快照、条数限制、输出内容及类型、中文和多页 PDF、前端筛选和下载流程。完成全量测试、构建和文档同步；不修改数据库结构，不访问生产数据或发送打印动作。真实 Windows 安装和厂内真实数据导出需单独验收。
