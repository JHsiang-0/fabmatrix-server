FabMatrix PDF font resource

NotoSansSC-Regular.ttf is a static weight-400 instance of Google's Noto Sans SC.
It retains the original full character map. PDFBox subsets the embedded font to
the glyphs used in each generated report. No system font or online fetch is used
at application runtime.
